# Supplementary recipe configurations

These 23 byte-preserved configurations identify the recipes used by the paper's
77 archived evaluated artifact/checkpoint units. `recipe-index.json` supplies
exact-file and canonical-JSON hashes, model/recipe names and recorded seeds.
`recorded-runtime.json` supplies the common recorded package versions, GPU and
numerical settings from all 77 saved metadata receipts. It excludes the separate
Mac/MPS judge environment and makes no common-driver or bitwise-equivalence claim.
The index covers evaluated historical screens and the completed one-seed pilot;
preflight-only failed candidates and the incomplete seed 1122 follow-up are not
represented as completed results. Fiction uses the corresponding Dolly recipe
with separately prepared data described in the paper.

This is configuration documentation, not a complete training harness or a release
of model states, prompts, answers or training rows. The separate version 2
numerical package reconstructs calculations from saved labels and aggregates.
Both packages are prepared locally; publication/upload remains an author action.

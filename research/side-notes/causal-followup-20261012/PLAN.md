The rate sum and optimizer-update mean are matched, not realized parameter-update
magnitude or an example-weighted exposure measure. Last batch size differs from
earlier batches, and AdamW dynamics are nonlinear. C-H changes peak, variance,
warmup and decay shape together; it does not isolate pure temporal ordering.
A stronger ordering-only follow-up would permute the same38 rates, fixing the
last rate to preserve the tail-batch exposure. That needs explicit-rate support
in a separately identified engine, real parity evidence and additional funding;
the current engineX is not silently monkey-patched to hide that change.

One new joint seed permits descriptive confirmation and a seed-specific timing
contrast. It cannot estimate a population effect/variance, guarantee power or
prove equivalence. The original600-answer endpoint retains invalid counts and
the same denominator. Benign refusal, common query likelihood and ARC stay
visible. Query/training disjointness is not independently established.

## Direct candidate intervention —1B only in this phase

Use the newly saved A/C/D adapters; no separate retraining. Fit one base-model
harmful-minus-task direction at fixed block ceil(.75L), from40 harmful and40 task
prompts. Choose these and evaluation membership by the frozen hash order; do not
select a layer/dose from intervention outcomes. Save the full vector, sign, layer
and all source/selection hashes privately. This is a candidate, not an already
validated refusal mechanism. Evaluation uses30 disjoint harmful and30 benign
prompts;20 additional task rows give an example-mean likelihood diagnostic.
All are known development prompts: fitting/evaluation are disjoint inside this
study, not globally untouched confirmation and not Main's hidden bank.

At the last prompt token during prefill only:

- Base: no hook, targeted projection ablation, and an equal-delta orthogonal
  direction control.
- Each A/C/D adapter: no hook, clamp its candidate projection to the clean base
  projection of that same input, and apply that equal-delta change orthogonally.
- Run exact-token no-hook/zero-sham canaries for every source context before the
  matrix. Record actual perturbations, dtype rounding and hook cleanup.
- Apply the same treatment rules to harmful and benign inputs. Guard scoring is
  separate, after policy hooks are removed; record guard isolation. No target
  answer/label is used to choose a clamp value.

Primary pilot outcomes: Unsafe and refusal labels in a **256-token greedy window**,
with invalid/truncation counts and benign refusal;20-task NLL under the matching
prompt-position intervention. These are not the original600 sampled/full-window
endpoint. A specific effect surviving orthogonal controls supports a contribution
of this candidate at this checkpoint, not a sole mediator, percent mediated,
general safety improvement or parameter-count law. A null result at this fixed
layer does not disprove all refusal mechanisms.

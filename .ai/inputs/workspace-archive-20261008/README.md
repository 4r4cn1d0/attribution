# Workspace archive, 8 October 2026

This folder keeps the files of the finished delegated-worker workspaces under `tmp/claude-workspaces/` that git did not already hold, so that those workspaces could be moved to the Trash; the workspaces were trashed after this archive was made and checked. It covers 19 workspaces (all except `review-fixes-round6-20261008` and `token-mean-loss-20261008`, which were kept, and `headroom-v2-engine-20261005`, which was handled earlier). A file is here when `git hash-object` of its content is not an object in the main repository (92 files), or when its object exists only as a dangling blob (6 files) or only through a `refs/codex` checkpoint ref (4 files); `.DS_Store`, `__pycache__` and 28 regenerable `.pytest_cache` files were left out. Each file keeps its `<workspace>/<path in the workspace folder>` path, and `index.jsonl` gives its workspace, path, size, SHA-256, git blob oid and why it is unique. A secret scan (Hugging Face, RunPod and GitHub tokens, private-key blocks, SSH keys) found no key material. The five files that `index.jsonl` marks with `proposed_destination` (four public tokenizer files and one text-to-speech probe recording, about 20 MB) are proposed for a private release instead of git.

Five files are listed in index.jsonl with archived=false and their SHA-256: four public tokenizer files (re-downloadable at their pinned revisions) and one stray audio file. They were not kept.

# GPT first-pass alternatives, 2026-10-02

Written before reading Opus's design response. Shared project history/FOCUS are not blinded. Latest human authorization removes the $10 financial cap ("no cap whatever is needed"); cost still must be justified and idle resources terminated. Old training/generation caps were engineering choices, not research requirements.

Option A: finite, fully observed removal grid plus strictly masked selector replay. Train every development and held-out candidate from the same base checkpoint; preserve nested short/full fidelities and paired seed controls. Fit matched-capacity predictors using group-disjoint development only; compare identical simple acquisition/choice logic with/without a published checkpoint-gradient feature. For each selector execution, expose only its purchased low/high-fidelity observations, reserve a fresh final-training seed and hidden reference seeds/prompts. S- can spend attribution's prerequisite + scoring cost on more runs. Reference computation is study cost, never free information to selectors. This is auditable and avoids inventing an allocator, but naive massive menu bootstrap would manufacture replication; intervals must reflect independent seeds and a small, fixed menu universe honestly.

Option B: prospective online selector for a few disjoint menus, each with independent seed executions and full hidden reference evaluation afterward. Fewer unused full runs and more direct cost fairness; greater engineering complexity, run-to-run time affects allocation, fewer menu units and difficulty separating information from optimizer failures. A generic successive-halving/racing selector can be an initial screen but is not equivalent to state-of-art constrained BayesOpt. No new allocator claim.

Preference pending Opus review: A for the initial experiment, explicitly a finite-menu feasibility study. Remove sparsity by complete shuffled epochs (retained rows each seen equally often); use several short checkpoints and a fixed final epoch count selected on development training/behavior curves, not held-out gains. Avoid single epoch=128 rows by an explicitly characterized larger sample or full corpus. Number of groups/seeds/eval prompts must follow precision/workload estimates, not the old16step/6prompt limits. Use independent test removal-row pools, outcome prompts and fresh selector/reference seeds; all models remain exposed to the common base SFT corpus so 'held-out group' means unavailable removal outcomes, not unseen training examples.

Measurement: preserve toxicity as primary unless explicit protocol amendment justifies harmful assistance. ToxicBERT was trained for comment toxicity and cannot be sole evidence for unsafe compliance. Audit exact received prompt/output blinded; separately label toxicity, harmful assistance, refusal, benign helpfulness. Model-assisted labels are not human gold. Expand generation until EOF on development, measure censoring and scorer truncation, freeze a generous technical cutoff with sensitivity/abstention rules. Benign NLL is a proxy, not established capability retention. An accessible calibrated safety/refusal classifier and deterministic task-correctness evaluation are preferable; WildGuard weights are gated, so do not silently depend on access.

Attribution: checkpoint-summed per-example query gradient dot-products/cosines (TracIn-inspired/LESS-style as precisely implemented) are a realistic first feature; plain mean-gradient cosine at one posttraining checkpoint is too weak to represent the literature. Do not call a variant exact LESS/SOURCE or treat a local derivative as finite-removal causal influence. Query harmful references must be disjoint from choice/hidden evaluation. Charge baseline checkpoint construction and all gradient costs, including failures.

Rigor: report choice effect paired across fresh seed blocks; expected feasibility has uncertainty. Fix practical margin before confirmation, show sensitivity rather than inventing a desired positive effect size. An initially inconclusive study is useful; no pretense that small N attains definitive power. Need stronger method/scorer ablation or another setting before paper-grade conclusions.
